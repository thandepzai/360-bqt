# 360 Động Từ Bất Quy Tắc - by MapStudy

Trang web tra cứu và luyện tập 360 động từ bất quy tắc tiếng Anh, được phát triển bởi [MapStudy](https://mapstudy.edu.vn).

## Tính năng

- 360 động từ bất quy tắc đầy đủ V1, V2, V3, phiên âm IPA, nghĩa tiếng Việt và ví dụ
- Tra cứu nhanh với tìm kiếm thời gian thực và lọc theo chữ cái
- Trang chi tiết cho từng động từ với gợi ý ghi nhớ
- Chế độ luyện tập flashcard ngẫu nhiên
- Thiết kế responsive, tối ưu cho cả desktop và mobile

## Công nghệ

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

## Khởi chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Build production

```bash
npm run build
npm start
```

## Cấu trúc

```
app/             # các trang App Router
components/      # các component dùng chung
data/            # dataset 360 động từ
lib/             # tiện ích, cấu hình site
styles/          # CSS toàn cục
```
